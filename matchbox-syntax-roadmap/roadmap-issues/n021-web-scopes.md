# N021: Web Scopes

**Type:** Web runtime
**Priority:** High

## What to build

Expose request-scoped and session-scoped structs in web execution contexts.

## Acceptance criteria

- [ ] `url`, `form`, `cookie`, `session`, `request`, `cgi`, and `server` scopes exist
- [ ] Request data is accessible in templates and scripts
- [ ] Session persistence works across requests
